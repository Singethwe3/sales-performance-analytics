# Sales Performance Analytics & Business Intelligence

## Project Overview
An end-to-end data analytics project focused on analysing sales performance, profitability, customer segments, and regional trends using Excel, Python, SQL Server, and Power BI.

## Tools and Technologies
- **Excel:** Data exploration and analysis
- **Python:** Pandas, data cleaning, exploratory data analysis, and visualisation
- **SQL Server:** Data validation, aggregation, and business analysis
- **Power BI:** Interactive dashboard development and KPI reporting
- **VS Code:** Project development and organisation

## Dataset
The project uses a sales dataset containing 10,194 records, including order details, customer information, product categories, sales, discounts, and profit.

## Key Performance Indicators
| Metric | Value |
|---|---|
| Total Revenue | $2,326,534.35 |
| Total Profit | $292,296.81 |
| Profit Margin | 12.56% |
| Unique Orders | 5,111 |

## Project Workflow
1. Imported and explored the sales dataset using Excel and Python.
2. Cleaned and prepared the data for analysis.
3. Imported the prepared data into SQL Server.
4. Analysed sales performance using SQL queries.
5. Developed Power BI visualisations to present business insights.

## Analysis Areas
- Revenue and profitability
- Sales performance by product category
- Regional sales performance
- Monthly and yearly sales trends
- Customer segment analysis

## Repository Structure
